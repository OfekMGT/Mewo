# Mewo

A tiny neon cat-clicking game where cats pop, bounce, and disappear with a satisfying sound.

## Run locally

```bash
cd /home/ofek/ros2_ws
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## GitHub Pages

This project is set up as a static site and includes a GitHub Actions workflow for automatic deployment to GitHub Pages.

1. Push this repo to GitHub.
2. Open your repository settings.
3. Go to Pages.
4. Choose GitHub Actions as the source.

Your site will be published at:

```text
https://<username>.github.io/Mewo/
```
